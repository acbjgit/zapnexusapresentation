## ⚡ Passo a Passo para Ativar o GitHub Pages:

### Opção 1: Criando um repositório exclusivo para a página (Mais Simples)
1. Acesse o [GitHub](https://github.com/new) e crie um novo repositório (ex: `zapnexus-apresentacao` ou `zapnexus`).
2. Arraste e solte o arquivo `index.html` (que está na pasta `landing-page`) diretamente na raiz do repositório no GitHub.
3. No seu repositório no GitHub, clique em **Settings (Configurações)** ➔ Menu lateral **Pages**.
4. Em **Build and deployment > Source**, selecione:
   * Branch: `main` (ou `master`)
   * Pasta: `/ (root)`
5. Clique em **Save**.
6. Pronto! Em 1 minuto seu link estará no ar: `https://seu-usuario.github.io/zapnexus/`.

---

### Opção 2: Usando a pasta `/docs` no repositório existente
1. Caso você já tenha o repositório do ZapNexus no GitHub, basta fazer o push da pasta `/docs/index.html`.
2. Em **Settings ➔ Pages** do repositório, selecione a pasta `/docs` como fonte do Pages.
3. Clique em **Save**.
